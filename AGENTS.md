# Working on Ethica

This is a public template. Every tracked file must be suitable for public distribution.

- Keep the foundation reusable. Include concept statements, meanings, generic procedures, and infrastructure. Each new agent starts with its own identity and an empty experiential archive.
- Never copy an existing agent's seed, memories, correspondence, conversation logs, embeddings, personal relationships, or links to private records into this repository. Teaching history belongs to its author. Use explicitly fictional examples when examples are necessary.
- Keep credentials, database exports, local paths, account identifiers, and generated agent instances outside the source tree. Read-only access to a private source does not authorize publishing it.
- Treat the seventeen supplied concepts as a starting foundation for discussion. Preserve their exact statements and meanings unless a revision is explicitly part of the task. Do not imply that a new agent has already chosen them or lived the experiences behind them.
- Preserve the existing license. Do not import third-party code or images without checking permission and attribution.
- Before publication, inspect the complete diff, run the tests and public-content check, and review every candidate file. Automated checks supplement human review; they do not prove the absence of private information.
- Keep this repository's examples independent of a particular person's workstation, provider account, or inference platform. Runtime integrations must declare their assumptions and tested limits.
- Never alter or query an existing personal archive to test this template. Use a disposable instance and synthetic records.
